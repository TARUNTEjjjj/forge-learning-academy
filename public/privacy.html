The browser learning edition

Your learning. Your files. Your browser.

Forge saves your learning record on the browser and device you are using. This edition has no account sign-in and does not send your learning record to a Forge account or database.

Keep an exported copy of work that matters to you. Clearing website data, changing browsers, or using private browsing can make saved work unavailable.

What stays in this browser

Forge uses browser storage, including localStorage, for your profile preferences, lesson notes and completion marks, study sessions, practice results, Python drafts, and project files. A competition timer may also use storage that belongs to its browser tab.

These records belong to this website address in this browser. They do not automatically follow you to another browser, device, or website address. People who use the same browser profile can see its saved learning record.

If storage is blocked or full, a save can fail. Pay attention to the storage notice and download your files before closing the page.

Keep a copy outside the website

  • In My progress, use Export my learning record to download a JSON copy of your saved record.
  • In Build & contribute, use Download project ZIP to save editable project files to your computer.
  • Keep downloads in a folder you can find again. They may contain your notes or source code, so review them before sharing.

Project publishing happens through your own Git and GitHub tools. Forge's browser edition does not connect to your GitHub account or push commits for you.

Clear your learning data

Open My progress, choose the delete-data action, and read its confirmation. This clears the active Forge learning record and its drafts in this browser. You can also remove this website's data in your browser settings.

Deleting website data does not delete files you downloaded, copies in another browser, or repositories you published on GitHub. Remove those separately if you no longer want them.

Requests outside your browser

Your browser requests the website's HTML, styles, scripts, and curriculum from the hosting provider. Font files may load from Google Fonts. Python practice downloads the pinned Pyodide runtime from this website's hosting provider. Because the runner is isolated from this website, browsers such as Chrome download those public runtime files again for every run instead of reusing a cached copy. Your code runs locally in a fresh, isolated browser worker; it is not sent to a grading server.

Documentation, contest judges, GitHub, and career resources open on their own websites. The hosting provider and these external services may process request information such as your IP address under their own policies. Their accounts and submissions are separate from Forge.

Keep passwords, access tokens, private customer data, and other sensitive information out of practice code, project files, and learning notes.

Resource collections

While Forge is open, a background client checks this project's public GitHub resource catalog on startup and every 15 minutes, and checks when due after you return or reconnect. The request contains no account credentials, lesson progress, or notes. Validated resource metadata is saved in this site's browser storage, and a service worker scoped to the resource library saves its page for offline visits. Clearing site storage removes these copies. External repository content still requires a connection.
